# 📚 作业通 HwCounter

一款为老师打造的 **收作业神器**（Android · arm64-v8a）：拍一张照片就知道谁交了、谁没交，自动扣分、一键导出 Excel。

## ✨ 功能一览

| 模块 | 能力 |
|---|---|
| 📸 **拍照识别** | 拍照或相册多选（最多 20 张），识别作业本封面的 **学号 / 姓名 / 二维码**，自动去重合并；照片上用彩色框标出识别位置；可手动勾选/补录 |
| 🎥 **实时扫描** | CameraX 实时取景，逐本翻开对准封面，识别到即“嘀”一声 + 震动；支持手电筒、暂停 |
| 📏 **侧面学号** | 学号写在作业本侧面，拍一摞的侧面：自动判断方向、高清分块 OCR，按叠放顺序列出每本是谁的，同时数出本数；条纹计数复核，提示可能漏读的本数；未对上名单的可点选指派 |
| 📦 **数本数** | 拍一摞作业本侧面，在照片上画一条“扫描线”，算法（带宽采样→去趋势→自相关估计厚度→峰值检测）自动数出本数，可点击增删标记；也可让 AI 数 |
| 🧠 **本地 / AI 双引擎** | 默认 ML Kit 中文 OCR **完全离线**；可接入任意多模态大模型：DeepSeek（视觉模型直接看图，或文本模型对本地 OCR 结果纠错匹配，照片不出手机）、通义千问 VL、豆包、智谱 GLM-4V、Kimi、硅基流动、OpenAI、Claude、本地 Ollama（OpenAI 兼容协议 / Anthropic 协议），可一键获取服务商模型列表 |
| 🔢 **智能匹配** | 自动纠正 O→0、l→1、S→5 等误识；学号被空格隔开、嵌在长串中都能识别；可选 1 位模糊匹配、姓名匹配 |
| 🏷️ **学号二维码贴纸** | 一键生成 A4 PDF（3×7），贴在作业本封面，识别率接近 100% |
| ✅ **状态登记** | 已交 / 优秀 / 迟交 / 未交 / 请假 / 未登记；点按切换、长按详情、批量操作、剩余一键标未交、撤销 |
| 🏖️ **请假** | 单次请假，或“长期请假”（之后新作业自动标请假，不扣分） |
| 🧮 **积分** | 规则可配（默认：初始 100，未交 −2，迟交 −1，优秀 +1），改规则后历史自动重算；手动加减分 + 快捷理由；个人榜（领奖台动画）/ 小组榜 / 催交榜 |
| 📊 **统计** | 提交率趋势柱状图、状态环形图、各科对比、全班作业热力图、全勤之星 |
| 📤 **导出** | Excel（总表 + 积分榜 + 积分明细 + 规则，带颜色）、CSV、精美“战报”海报图片、家长群文字通报 |
| 📥 **导入名单** | JSON（多种结构、中英文字段名自动识别）/ CSV / 直接粘贴 Excel 两列；合并、替换或新建班级 |
| 🔊 **语音播报** | TTS 朗读未交名单 |
| 🎲 **随机点名** | 老虎机式滚动抽人，可直接加分；也能“从未交中抽” |
| 🎨 **多风格** | 10 套主题（薄荷/学院蓝/樱花/暖阳/赛博霓虹/森林/纸本手账/葡萄汽水/水墨/Material You 动态取色）× 深浅色 × 3 种圆角 × 4 种排版（卡片/列表/座位表/分组）× 紧凑模式 |
| 🏫 **多班级** | 班级切换、每班独立名单/作业/积分 |
| 💾 **备份** | 全量 JSON 备份/恢复；全员交齐放彩带 🎉 |

## 📥 名单 JSON 格式

```json
{
  "className": "高一(3)班",
  "students": [
    { "no": "202401", "name": "张三", "group": "第1组", "gender": "男" },
    { "no": "202402", "name": "李四", "group": "第1组" }
  ]
}
```

也支持 `[{"学号":"01","姓名":"张三"}]`、`{"202401":"张三"}`，以及每行 `学号,姓名,小组` 的 CSV/TXT。

## 🛠️ 构建

- Kotlin 2.0 + Jetpack Compose（Material 3）+ CameraX + ML Kit（模型随包，离线可用）
- `minSdk 26`，`targetSdk 34`，仅打包 `arm64-v8a`
- 推送代码后 GitHub Actions 自动构建，APK 在 Actions 页面的 **Artifacts** 中下载；推送 `v*` 标签会自动发布 Release。

```bash
./gradlew assembleRelease
# 输出：app/build/outputs/apk/release/app-release.apk
```

> 仓库内置的 `app/hwcounter.jks` 仅用于让每次构建签名一致、可覆盖升级；正式上架请换成自己的签名。
