# 📚 作业通 HwCounter

一款为老师打造的 **收作业神器**：拍一张照片就知道谁交了、谁没交，自动扣分、一键导出 Excel。

**三端同步**：📱 Android（arm64-v8a）· 📲 iPad 原生 App（SwiftUI）· 🌐 网页版 <https://deepshawn.github.io/hwcounter/>
数据通过 Supabase 云端同步；**不登录也能预览（只读），登录后才能修改**。

## ✨ 功能一览

| 模块 | 能力 |
|---|---|
| 📸 **拍照识别** | 拍照或相册多选（最多 20 张），识别作业本封面的 **学号 / 姓名 / 二维码**，自动去重合并；照片上用彩色框标出识别位置；可手动勾选/补录 |
| 🎥 **实时扫描** | CameraX 实时取景，逐本翻开对准封面，识别到即“嘀”一声 + 震动；支持手电筒、暂停 |
| 🎙️ **语音登记** | 连续念名字或学号，听到一个登记一个（滴声提示）；拼音模糊匹配（声母韵母混淆矩阵 + 对齐，容忍口音、多音字姓氏、漏字多字、只叫名、拼音首字母如 ZJY=张锦宇）；支持“三十四号”“三四”“幺零三”、连着说的“3449”；可选登记为已交/优秀/迟交/未交/请假；歧义点选、逐条撤销；无系统语音服务时可用输入法语音输入 |
| 📏 **侧面学号** | 学号写在作业本侧面，拍一摞的侧面：自动判断方向、高清分块 OCR，按叠放顺序列出每本是谁的，同时数出本数；条纹计数复核，提示可能漏读的本数；未对上名单的可点选指派 |
| 📦 **数本数** | 拍一摞作业本侧面，在照片上画一条“扫描线”，算法（带宽采样→去趋势→自相关估计厚度→峰值检测）自动数出本数，可点击增删标记；也可让 AI 数 |
| 📄 **数试卷** | 专为极薄纸张优化：原图分辨率 + 亚像素采样、自动对齐纸边、9 线投票、周期法与逐缝跟踪互证并给出置信度；拖动端点带放大镜，放大条带逐张核对。合成测试（每张 ≥2.5 像素）±1 准确率 99.8%，见 `tools/paper-sim` |
| 🧠 **本地 / AI 双引擎** | 默认 ML Kit 中文 OCR **完全离线**；可接入任意多模态大模型：DeepSeek（视觉模型直接看图，或文本模型对本地 OCR 结果纠错匹配，照片不出手机）、通义千问 VL、豆包、智谱 GLM-4V、Kimi、硅基流动、OpenAI、Claude、本地 Ollama（OpenAI 兼容协议 / Anthropic 协议），可一键获取服务商模型列表 |
| 🔢 **智能匹配** | 自动纠正 O→0、l→1、S→5 等误识；学号被空格隔开、嵌在长串中都能识别；可选 1 位模糊匹配、姓名匹配 |
| 🏷️ **学号二维码贴纸** | 一键生成 A4 PDF（3×7），贴在作业本封面，识别率接近 100% |
| ✅ **状态登记** | 已交 / 优秀 / 迟交 / 未交 / 请假 / 未登记；点按切换、长按详情、批量操作、剩余一键标未交、撤销 |
| 🏖️ **请假** | 单次请假，或“长期请假”（之后新作业自动标请假，不扣分） |
| 🎯 **个人分析与关注度** | **关注度指数**（0–100）：由缺交风险、连续未交、交齐差距、近期下滑、考试偏弱、考试退步、积分靠后加权算出，分重点关注 / 需要关注 / 留意 / 正常；统计页“关注”栏目按指数排序，显示主要原因、近 8 周走势和较上周变化，数据一变立即重算。**个人分析报告**：综合评价与建议、关注度构成、作业与全班对比、连续记录、足迹、各科 / 星期 / 按月、积分走势与来源、考试、各轮、结算、小组，可导出 PDF |
| 🧾 **结算与积分流水** | **结算**：按本轮交齐度（全勤 +5、≥95% +3、90–95% +1、80–90% 0、70–80% −2、<70% −5）和缺交情况（缺交 ≥5 次 −3、最长连续缺交 ≥3 次 −2）给分，另有进步奖、小组奖，以及按综合表现指数（交齐、按时、优秀、缺交、考试、进步，标准分加权）扩大区分度的加减分（单人最多 ±10，全班合计约为 0）；结算后自动打开按学号排列的积分登记表（可复制、导出 Excel）；预览后可逐人调整，结算后可随即开始新一轮，结算记录可导出 Excel / PDF、可撤销，每月定期重置前自动结算。**积分流水**：全班或单个学生每一笔加减分，按类型和时间筛选，导出 Excel / PDF。**计分规则通知**：按当前规则一键生成 PDF |
| 🧮 **积分** | 规则可配（默认：基准 100，迟交 −1，优秀 +1；**未交连续自动扣分，三种方式可选**：① 正常加倍 −2、−4、−8、−16……；② 第 2 次起加倍（默认）−2、−2、−4、−8……；③ 分段倍率：在 ① 或 ② 的基础上按次数分段再乘倍率（默认第 1–2 次 ×1、第 3–4 次 ×1.5、第 5 次起 ×2，段数、起始次数、倍率都可调，可按连续次数或本轮累计次数分段）；请假和未登记不打断，交过一次就重新算；**间断未交平衡**（默认开启，可关闭）：次数取连续未交次数和最近 6 次作业里的未交次数中较大的，间断未交最多按第 3 次算（都可调），隔几次不交一次也会适度加重（隔一次不交一次：−2、−2、−4、−4、−4……）；本轮累计未交超过 6 次后底数改为 3（②：−3、−3、−9、−27……）；每次积分重置后重新开始；单次最多扣 30 分（可改，0 为不限，分段倍率乘完后再封顶）；可关闭改回固定扣分）；**连续交奖励**：本轮连续按时交满 5 次后，之后每连续交一次额外 +1（请假不打断，未交、迟交打断，每轮重置重新计）；**取整**：最终显示的积分取整，正分向上、负分向下（单笔加减分保留原值），改规则后历史自动重算；手动加减分 + 快捷理由；点击“多选”后逐个点学生统一加减分；**🔄 积分重置**：全班或选中学生的积分重置为指定分数并留下重置记录，此前的加减分、作业状态、未交次数全部保留，可随时撤销；个人榜（领奖台）/ 小组榜 / 催交榜 |
| 📊 **统计与分析** | 作业与考试分开统计。作业分 **全部（有记录以来）/ 本轮（最近一次全班重置以来）/ 近 10 次**，还能**按年、季度、月、周、日**查看（可往前翻），或**自定义起止日期**，并与上一时段（上月、上周……）对比；**进步之星 / 退步关注**：比较每位同学“以往（重置前）”与“重置后”的交齐率、按时率、优秀率和考试得分率，可直接给他们加减分；按日/周/月汇总、各轮对比（以全班重置为分界）、积分来源与常见加减分原因、学生分层（全勤/稳定/波动/需关注）、下次缺交风险预警、偏科提醒、连续交齐榜、交齐率中位数与离散度；自动生成“主要发现”（趋势回归、科目/星期差异、连续未交、小组差距、作业与考试相关性、数据完整度等）；交齐率/按时率/优秀率/缺交率/迟交率；趋势、每次构成、状态分布、**全班作业热力图**、可排序的学生明细、交齐率分布、全班积分走势、积分涨跌、小组对比（含组长）、各科、星期、需要关注、进步之星、全勤之星；**一键生成分析报告**（文字复制/分享、**PDF**（排版好的多页报告，含图表，可直接打印）或多表 Excel） |
| 📝 **考试** | 新建或导入考试（**拍照识别成绩表**：配置了 AI 时由大模型看图转录表格，否则本地离线识别；也可粘贴 / CSV / Excel，可一次导入多科、每列一场，自动识别姓名学号列、分数列和缺考）；**缺考**：录入成绩后也能单人记为/取消缺考（点学生或长按）、多选批量记为缺考 / 取消缺考 / 清除成绩、“未录入的记为缺考”、导入预览时点一行改为缺考、导入时把表里没有的同学记为缺考，缺考可单独设加减分；每场显示平均/中位/最高/最低/标准差、优秀/良好/及格/低分率、分数段；**按排名或按学号**查看，显示与上一场同科考试的名次进退；可按得分率分档**自动加减积分**（默认 ≥90% +2、80–90% +1、<60% −1，可在设置中修改，单场可关闭）；考试分析含均分走势、各科对比、名次进退、学生稳定性和小组对比，以及难度与区分度、四分位、考试进步之星 / 退步关注（按相对班级平均的位置，可直接加分）、成绩层级与层级流动、临界生、连续上升/下滑、偏科、作业与考试对照、男女生对比；单场考试有“深入分析” |

## 🧮 批量加减分与重置

- **批量加分页**（首页「批量加分」或积分页 ⋯ → 批量加减分）：按条件一键选人——全班、各小组、最近一次作业优秀/按时/未交/迟交、进步之星、退步关注、全勤、连续未交、最近一场考试 ≥90% / <60% / 缺考、积分最高/最低 5 人；可**统一分值**，也可**逐人设不同分值**，确认前显示每人加减后的积分，可整批撤销。
- 在“积分”页点击 **多选**，再点选学生；支持全选、清空选择和取消。点击 **批量加减分**，设置每人的分值和原因，确认后统一生效，可整批撤销。
- 积分页可切换 **按积分 / 按学号**；学号按自然顺序升序排列（1、2、10），并记住本机选择。切换排序保留真实积分名次和多选对象。
- 每次作业的学生名单也支持 **多选**，卡片、列表和座位表均可使用；可按当前筛选全选，批量登记状态或额外加减分。额外加减分会记录作业名称，并保留提交状态和未交次数。
- **修改基准分**：可随时将 100 改为 0 等任意分数，适用于所有班级，历史加减分继续计入。例如基准 100、未交扣 6、手动加 2，当前 96；基准改为 0 后为 −4。

## 🔄 积分重置

- 在“积分”页右上角 **⋯ → 全班积分重置**，或开启 **多选** 后点 **积分重置**，填写要重置为的分数（默认基准分）和备注（如“期中重新计分”），确认前可预览每人重置前后的分数。
- **只重置积分**：重置后的积分 = 重置分数 + 重置之后布置的作业自动计分 + 重置之后的手动加减分。
- **选择从哪天起重新计分**：生效时间可选 **立即**、**从某次作业起**（含该作业，之后的作业和这次作业布置后的加减分计入）或 **从某一天起**（当天 0 点起）。可以事后补一次“从开学那天起”的重置；同一位同学有多次重置时，以生效时间最晚的那次为准。
- **记录保留**：此前的加减分流水、作业状态、备注、未交次数一条不删，个人详情里照常显示，并标注“重置前，不计入当前积分”；重置本身也作为一条记录出现在流水中。
- **可追溯、可撤销**：“重置记录”列出每次重置的时间、分数、人员及每人重置前分数；删除某次重置即恢复按之前的记录计分。修改计分规则或基准分不会改变已重置同学的起点。
- **每月定期重置**：积分页 ⋯ → 每月定期重置，设定每月几号（1–28）和重置分数。每月该日 0 点起全班自动重置（打开 App 时补上），记录与手动重置相同，带“每月定期”标记；撤销某个月后不会再自动补回。三端同一算法，多台设备同时补也不会重复。
- Excel 导出新增“积分重置记录”工作表；三端（Android / iPad / 网页）同一格式、同一算法，云端同步时按记录合并。

## 📥 名单 JSON 格式

```json
{
  "className": "高一(3)班",
  "students": [
    { "no": "202401", "name": "张三", "group": "第1组", "gender": "男" },
    { "no": "202402", "name": "李四", "group": "第1组" }
  ]
}
```

也支持 `[{"学号":"01","姓名":"张三"}]`、`{"202401":"张三"}`，以及每行 `学号,姓名,小组` 的 CSV/TXT。

## 🛠️ 构建

- Kotlin 2.3 + Jetpack Compose + [miuix](https://github.com/compose-miuix-ui/miuix)（HyperOS 风格组件）+ [backdrop](https://github.com/Kyant0/AndroidLiquidGlass)（液态玻璃）+ CameraX + ML Kit（模型随包，离线可用）
- `minSdk 26`，`compileSdk 36`，`targetSdk 35`，仅打包 `arm64-v8a`
- 推送代码后 GitHub Actions 自动构建，APK 在 Actions 页面的 **Artifacts** 中下载；推送 `v*` 标签会自动发布 Release。

```bash
./gradlew assembleRelease
# 输出：app/build/outputs/apk/release/app-release.apk
```

> 仓库内置的 `app/hwcounter.jks` 仅用于让每次构建签名一致、可覆盖升级；正式上架请换成自己的签名。
